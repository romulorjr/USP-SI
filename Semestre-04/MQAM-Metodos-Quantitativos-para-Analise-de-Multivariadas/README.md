# MQAM - Métodos Quantitativos para Análise Multivariada

Esta disciplina foca no estudo e aplicação de técnicas estatísticas para análise de conjuntos de dados com múltiplas variáveis, utilizando ferramentas computacionais para suporte à decisão.

## Conteúdo da Disciplina
- Análise de Variância (ANOVA/MANOVA).
- Regressão Linear Múltipla.
- Análise de Componentes Principais (PCA).
- Análise de Agrupamentos (Cluster Analysis).
- Análise Fatorial.
- Análise Discriminante Linear (com e sem balanceamento)
- Escalonamento MultiDimensional
- Análise de Clusters

## Projetos e Exercícios
Os projetos desta matéria foram desenvolvidos utilizando **Python** no **Google Colab**.

## Como Executar os Notebooks
Para que o código funcione corretamente, o notebook espera encontrar os dados no seu Google Drive. Siga os passos:

1. No seu Google Drive, crie uma pasta chamada `Colab_Notebooks`.
2. Baixe os arquivos CSV disponíveis no link abaixo e coloque-os dentro dessa pasta.
3. Ao abrir o notebook no Colab, autorize a conexão com o Google Drive quando solicitado.

**Link para os Dados:** [Pasta do Drive com CSVs](https://drive.google.com/drive/folders/1J5skwEsOKB6nUSQPu5NiLB-0ODg4MRcu?usp=drive_link)
